# VidRush graphics catalog

Read off four VidRush exports (89.5 minutes, 1,791 frames sampled every 3 s,
first frame of every graphic appearance reviewed by eye). This is the source
for the Remotion library and for the director's GRAPHICS LIBRARY prompt.

## How often and how long

| measure | value |
| --- | --- |
| frames with a graphic on screen | 53 % |
| graphic appearances | ~60 per 10 minutes (one every ~10 s) |
| typical hold | 4–6 s (maps and timelines 6–7 s) |
| plain frames: video vs still | 59 % video / 41 % still |
| cut length | median 3.3–3.7 s, 13.6–16.5 cuts per minute |

Most graphics **ride on playing footage**. Full-frame cards (document,
chapter, chart) are the minority and never back to back.

Transitions (entrances): cut, fade, film-burn, whip, flash, zoom, light-leak,
slide, dip, punch, glitch, blur. About one real transition per four cuts, at
section changes, rotated so neighbours never look alike.

Clip effects: ken-burns, light-leaks, dust, film-flicker, colour-shift.

## Not auto-planned

`photo-card`, `name-card` and `split` frame the media on a backdrop. The
creator rejected that look; media always plays full screen.
